# Scope of the Penumbra / TexTools project

Working scope list cleaned up from the original notes. Items are grouped by theme; order within a group is roughly priority / dependency, not a firm roadmap.

## Platform & runtime

- Make both apps compatible with Windows and Linux
- Support running while the game is open or closed
- Improve app performance

## Research & architecture

- Research and reverse-engineer both Penumbra and TexTools to understand how they work
- Review the architecture of both apps and determine whether they can run together in-game
- Re-evaluate Penumbra’s app structure and make it easier to navigate / find what you need

## Body types, hair & sculpts

- Support easy upscaling to any body type, including Lalafell
- Include hair and sculpts in that upscale / conversion path

## Penumbra workflow

- Provide an easy way to upload to Penumbra
- For the desktop version: make the app easy to find, and add a simple upload-to-Penumbra flow

## Authoring tools

- Tattoo converter to make tattoos easier to create
- Make coloring of items easier
- Make the app easily customizable

## Exploratory / maybe later

- Possible linking to Blender
- Possibly make dance creation easier
